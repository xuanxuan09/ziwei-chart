# 紫微斗数排盘（离线单文件版）

一个纯前端的紫微斗数排盘页面，双击 HTML 即可使用，也可直接部署到 GitHub Pages。
计算引擎为开源库 [iztro](https://github.com/SylarLong/iztro)（MIT），已打包内联进 `index.html`，**页面运行时不发起任何网络请求**，所有排盘计算都在浏览器本地完成。

## 功能

- 公历 / 农历（含闰月）输入，13 个时辰（含早子时、晚子时），性别
- 十二宫盘面：宫名、干支、主星及亮度（庙旺得利平陷）、生年四化、大限区间
- 中宫：四柱、五行局、命主身主、命宫身宫、生肖星座、当前大限、生年四化汇总
- 点击宫位查看详情：大限区间、小限年龄、长生 / 博士 / 将前 / 岁前、该宫在大限与流年中的角色、三方四正（盘面同步高亮）
- 运限年份可逐年切换：大限四化、流年四化、流年干支、虚岁

## 部署到 GitHub Pages

1. 新建仓库（Public），把本目录的 `index.html` 上传到仓库根目录
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存
3. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 说明

- 不同流派在「闰月归属、晚子时归属、五行局取法」上存在差异，本页以 iztro 引擎默认规则为准；宫名「仆役」按现代通称显示为「交友」。
